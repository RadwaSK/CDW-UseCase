# Legacy Order Service (synthetic demo fixture)

This is a **synthetic legacy demo application only**. It is not connected to any real system,
contains no real data, and is not intended to run as a production service. It exists purely as a
read-only fixture for the assessment workflow to analyze: it deliberately contains realistic
architecture smells, a weak query pattern, a fake hard-coded secret, and PII-bearing fields so the
security/governance and architecture agents have concrete, citable evidence to find.

Do not add real credentials, real customer data, or production configuration to this folder.
